**DineOps — For Customers**

- **What this app lets you do:**
  - Browse participating restaurants and view menus.
  - Place orders for dine-in (table), takeaway, or delivery (if enabled).
  - Save profile and payment preferences, view order history.

- **How to place an order (quick):**
  1. Select restaurant and menu category.
  2. Add items to cart and choose zone/table (if prompted).
  3. Checkout: select payment method and confirm.
  4. Track order status in the app (Preparing → Ready → Delivered).

- **Account & privacy:**
  - You can edit your profile and contact details in `Account`.
  - Personal data removal follows the platform's privacy policy; contact support for help.

- **Support & feedback:** Use the in-app support link or open an issue in the repository describing the problem.
