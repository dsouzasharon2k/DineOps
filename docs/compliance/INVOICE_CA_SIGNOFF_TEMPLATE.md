# Invoice and GST CA Signoff Template

## Purpose

Use this checklist to obtain Chartered Accountant review and signoff for invoice generation logic before broad production rollout.

## Scope Reviewed

- Tax invoice PDF generated by backend service
- GST breakup at invoice and line-item level
- SAC code display
- Supplier/buyer fields
- Invoice numbering sequence behavior

## Checklist

- [ ] Invoice number format and sequencing acceptable for business and jurisdiction.
- [ ] GSTIN and FSSAI handling rules are compliant for registered and unregistered entities.
- [ ] SAC code usage is correct for provided services.
- [ ] Line-level taxable value and CGST/SGST calculations are acceptable.
- [ ] Rounding policy is documented and legally acceptable.
- [ ] Terms, disclaimer, and mandatory invoice fields satisfy local requirements.
- [ ] Storage and retention policy for generated invoices is defined.
